# 일원 오락실 - 땅따먹기 v3.1

농부가 고랑을 파고, 홍게·청게를 피해 땅을 차지하면 풍경이 드러나는 버전.

## 주요 변경 (v3)
- 플레이어: 농부 캐릭터 (괭이로 파는 동작, 방향 반영)
- 적: 홍게(붉은) / 청게(푸른) — 몸통·집게·다리 애니메이션
- 지나간 자리: 고랑으로 표현
- 미점령 영역: 흙으로 덮임 → 점령 확정 시 흙이 걷히며 농촌 풍경 공개
- 점령률과 공개 영역 일치
- 기존 규칙(목숨, 목표 75%, 요금 신호, 대각선 조이스틱, S22 레이아웃) 유지

## v3.1 UI 개선
- **멈추기 메뉴**: 게임 중에는 `⏸ 멈추기` 버튼만 있음. 누르면 `계속하기 / 새 게임 / 나가기` 메뉴가 뜨고, 나가기는 한 번 더 확인 (키보드 Esc/P 로도 열림)
- **소수점 점령률**: `99.8%`처럼 소수 한 자리까지 표시. 내림 처리라 100% 미만이면 100.0%로 올라가지 않음
- **게 디자인**: 홍게=수컷(큰 집게, 등 가시), 청게=암컷(작은 집게, 흰 점무늬·속눈썹)으로 색과 집게 크기 구분. 새끼 게는 작은 집게
- **농부 모션**: 괭이를 천천히 들어 올렸다가 빠르게 내려찍는 동작, 걸음·몸 흔들림, 흙먼지
- **아케이드 메뉴**: 골드 테두리·네온 글로우·왕관/별/다이아 장식·이소메트릭 보드·입체 `GAME START` 버튼. 멈추기·결과 화면도 같은 카드 스타일 (`menu_card.md` 참고)
- `index.html`에 전체 게임 구현 (`node tests/game_logic_test.js` 로 로직 테스트)
