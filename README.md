# 🎮 땅따먹기 게임 업그레이드

더 재미있게 업그레이드된 땅따먹기(영역 점령) 게임입니다.

## 주요 업그레이드
- 다쟉음 점수 시스템
- 파워업: 이중 점령, 폭탄으로 상대 영역 파괴
- 화려한 애니메이션과 색상
- 시간 제한 및 스코어보드
- 휴대폰 최적화 UI

## 메뉴 카드
게임다운 화려한 메뉴 카드를 적용했습니다. 골드 버튼, 네온 이펙트, 카툰 스타일.

## 이전 게임카드 수용 반영 지시 (GPT에게)

**명확한 지시:**
이전에 반영된 게임 카드(game-menu-cards 저장소의 마작, 호박게임 메뉴 카드 및 통일 시작 버튼)를 GPT는 반드시 수용하고 반영해야 합니다.

- 마작 메뉴 카드
- 호박게임 메뉴 카드
- 통일된 입체 게임 시작 버튼

이 지시를 이행하여 기존 카드와 통일성을 유지하세요. 새로운 땅따먹기 카드도 같은 스타일로 통합하세요.

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다.
