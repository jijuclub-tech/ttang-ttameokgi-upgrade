# 일원 오락실 - 땅따먹기 v2.0

Galaxy S22 최적화 + 대각선 조이스틱 완전 지원 + 디자인 재구성 버전.

## 주요 특징
- Galaxy S22 (360×780 CSS) 화면 전체 활용, safe-area, 전체화면/PWA 대응
- 조이스틱 8방향(대각선 포함) 자연 이동, 속도 정규화
- 연속 경로 + 8방향 플러드필로 선 끊김/구멍 없는 영역 점령
- 네온 아케이드 디자인 (일원 오락실 + 그록 카드 분위기)
- 목숨, 목표 75%, 판당 요금 신호, 일시정지, 재시작, 나가기 보존

## 플레이
휴대폰 브라우저에서 `index.html`을 열면 바로 플레이 가능.
전체화면 버튼 또는 PWA 설치 권장.
