# 일원 오락실 - 땅따먹기 v3.0

농부가 고랑을 파고, 홍게·청게를 피해 땅을 차지하면 풍경이 드러나는 버전.

## 주요 변경 (v3)
- 플레이어: 농부 캐릭터 (괭이로 파는 동작, 방향 반영)
- 적: 홍게(붉은) / 청게(푸른) — 몸통·집게·다리 애니메이션
- 지나간 자리: 고랑으로 표현
- 미점령 영역: 흙으로 덮임 → 점령 확정 시 흙이 걷히며 농촌 풍경 공개
- 점령률과 공개 영역 일치
- 기존 규칙(목숨, 목표 75%, 요금 신호, 대각선 조이스틱, S22 레이아웃) 유지

## 사진 출처 참고
프로시저럴 풍경 사용. 실제 사진 교체 시 Unsplash/Pexels 농촌 풍경 (예: rice fields, countryside landscape) 라이선스 확인 후 사용 권장.
